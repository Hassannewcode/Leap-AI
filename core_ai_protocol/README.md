# CORE AI Protocol

This protocol is a sophisticated, alternative RAG (Retrieval-Augmented Generation) system designed to guide the Leap AI's development process. It establishes a framework for achieving high-quality, accurate, and creative results by focusing on a structured workflow, multi-faceted analysis, and a rigorous points-based evaluation system.

The protocol ensures that the AI doesn't just respond to prompts, but internalizes the user's vision, conducts thorough research, and produces a polished, fully-functional final product that exceeds expectations.

This directory contains the core documentation for this protocol, which the Leap AI uses as part of its prime directive.

- **[POINTS_SYSTEM.md](./POINTS_SYSTEM.md):** Details the CORE point earnings and penalties, the system used to measure AI performance.
- **[WORKFLOW.md](./WORKFLOW.md):** Outlines the mandatory workflow and task requirements the AI must follow to ensure quality and accuracy.
